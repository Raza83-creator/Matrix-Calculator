
# Matrix Calculator

## Introduction
Matrix Calculator is a C language project designed to perform different mathematical operations on matrices. It provides users with a simple menu-based interface to perform matrix calculations with showing steps.

## Objectives
- To understand the practical implementation of matrices in C.
- To use functions for different matrix operations.
- To improve problem-solving and programming skills.

## Features
- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Division
- Matrix Transpose
- Determinant Calculation
- Row Echelon Form
- Reduced Row Echelon Form

## Programming Language
- C Language

## Tools Used
- Dev-C++ / Visual Studio Code
- GCC Compiler
- GitHub

## How to Run
1. Download the source code.
2. Open the `.c` file in a C compiler.
3. Compile the program.
4. Run the program.
5. Select an operation from the menu.
